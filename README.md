# 🎃 南瓜留船（poi-plugin-nangua-liuchuan）

一个 [poi](https://github.com/poooi/poi)（舰娘浏览器）插件：根据你已有舰娘的「运」值，自动算出**每艘船还要再捞多少只**才够目标运（默认 51），帮你规划捞船和喂运（まるゆ）。

## 功能

- **剩余捞船**：自动列出所有运值未达目标的舰娘，每行直接显示还需要捞多少艘；**不需要再捞的行显示 ✅**
- **完整信息表**：舰种、舰娘、Lv、火力、雷装、火力+雷装、当前运、剩余运、已捞、剩余捞船、まるゆ(估)，一屏看全
- **已捞**：这条船（含改二、改三等所有形态）你已经捞到并上锁、且等级还不到留船标准的数量，自动扣减剩余捞船
- **留船等级上限**：设置留船等级后，低于该等级的船不算主力，直接从列表里消失
- **收藏置顶**：点击行首 ☆ 收藏，收藏的船固定排在最前面（📌），重启 poi 也不丢
- **排序与筛选**：点表头任意列即可排序；上方可只显示某一舰种
- **可调参数**：目标运（默认 51）和公式参数都能在插件里改，一键恢复默认
- **自动刷新**：出击归来、改造、喂运后自动重新计算
- **新窗口打开**：poi 插件设置里勾选 *Open plugin in new window* 即可在独立窗口显示

## 安装

### 方法一：poi 插件管理器（推荐）

1. 打开 poi → 左侧「插件」→ **插件管理器**
2. 搜索 `poi-plugin-nangua-liuchuan`（中文名「南瓜留船」）
3. 点「安装」，等待完成
4. **重启 poi**，在插件列表里启用「南瓜留船」
5. 进入游戏母港，数据会自动同步

### 方法二：手动安装

1. 把 `poi-plugin-nangua-liuchuan` 文件夹放进：

   ```
   %APPDATA%\poi\plugins\node_modules\
   ```

   （在资源管理器地址栏输入 `%APPDATA%\poi\plugins` 回车即可；没有 `node_modules` 文件夹就新建一个。注意：必须放在 `node_modules` 里，直接丢进 `plugins\` 下不会被 poi 识别）

2. 完全关闭 poi 再重新打开
3. 在插件列表里启用「南瓜留船」

> 绿色版 / 便携版 poi 的插件目录可能不同，以 poi 插件设置页提示的实际路径为准。

## 使用方法

- 打开插件即可看到所有「当前运 < 目标运」的舰娘
- **目标运**：默认 51，可在插件顶部设置区修改
- **剩余捞船 = 0** 的行表示这条船不用再捞了（显示 ✅）
- **まるゆ(估)**：把运喂到目标值大约需要的まるゆ数量，仅供参考
- 任意列点击表头即可排序

## 兼容性

支持 poi v10 及以上版本（对旧版 poi 也做了兼容）。
